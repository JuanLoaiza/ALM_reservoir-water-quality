# Correlation analysis reproducibility validation

## Scope

The portable `code/correlation/05_LULC_WQ_correlation.ipynb` was connected to the canonical outputs already validated in this repository: nine water-quality prediction workbooks and twelve zonal LULC-change workbooks. Google Drive mounting and private `/content/drive/MyDrive/...` paths were removed. Statistical formulas and analytical criteria were not changed.

## Validation results

The primary numerical outputs were regenerated and compared with the archived original outputs used in the analysis.

| Output | Structure | Maximum absolute numeric difference | Status |
|---|---|---:|---|
| `Exact_analysis_table.csv` | identical (180 x 29) | 5.33e-10 | PASS |
| `Lagged_analysis_table.csv` | identical (180 x 29) | 1.28e-09 | PASS |
| `Correlation_results.csv` | identical (30 x 29) | 5.62e-10 | PASS |
| `Unified_land_use_water_quality_results.xlsx` | identical sheets/structure | 1.68e-09 | PASS |

The differences are numerical floating-point precision only and do not represent scientific changes. The only non-numeric difference in the unified workbook is the `source_file` field: it now records normalized repository filenames rather than legacy Google Drive filenames (`N1_... (1).xlsx`).

## Analyses covered

The validated outputs include the exact and one-year-lagged scenarios, Pearson correlations, Spearman correlations, partial correlations controlling for period, and Benjamini-Hochberg-adjusted significance values generated by the notebook.

## Portability

The notebook contains no `/content/drive` or `MyDrive` references and reads from:

- `derived_data/water_quality_predictions/`
- `derived_data/lulc_change/`

Results are written to `results/correlation/`.

## Result

**PASS.** The portable correlation workflow reproduces the archived numerical results within floating-point precision.
